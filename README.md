# Paradise Nursery Shopping Application

An e-commerce web application built with React and Redux for an online plant shop called Paradise Nursery. Users can browse houseplants across multiple categories, view details, manage quantities, and see dynamic cost calculations.

## Features
- Interactive landing page with a "Get Started" button
- Product catalog categorized with distinct plant varieties
- Redux-powered shopping cart with dynamic item counts and total cost calculation
- Responsive navigation bar across views
